# UI/UX Redesign Task: Order Delivery Status Experience

## Context
The current application's order tracking interface only displays basic text states:
- Processing
- Shipped
- Out for Delivery
- Delivered

Users report that this current status view is confusing and difficult to understand at a glance. 

## Objective
Redesign and implement a modern, intuitive order tracking experience so the delivery status is clear immediately.

## Requirements
- Visual Delivery Timeline: Provide a clear, step-by-step visual progress timeline
- Current Order Status: Prominently highlight the active status of the order
- ETA: Display an estimated delivery date and time
- Order Summary: Include a concise summary of the ordered products
- Support Access: Provide a clear, easily accessible way to contact support
- State Management: Handle appropriate loading, empty, and error states seamlessly
- Responsive Layout: Optimize the design for mobile viewports, specifically targeting widths between 360px and 430px
- Design System: Maintain clean spacing, typography, clear hierarchy, and strong visual consistency
- Interactive Features: Implement meaningful micro-interactions. expanding order details, triggering support channels, or reporting a delivery issue.

##The UI must handle all three situations:
1. Delayed Order — the estimated delivery time has passed or the order is significantly delayed. Clearly communicate the delay and provide an appropriate next step.
2. Delivered but Not Received — the system says the order was delivered, but the customer reports they did not receive it. Provide an appropriate next step or support action.
3. Tracking Not Available Yet — the order exists, but tracking information is not available yet. Avoid an empty or broken-looking screen.
